Privacy Policy

Last updated: October 13, 2026

AI2Now Publisher is a private publishing tool used only by the owner of the AI2Now accounts.

What it accesses

When the owner connects a TikTok account, the tool receives an access token and a refresh token with the video.publish permission, and basic creator information needed to post (such as the account name and the privacy options available for a post). It uses these only to upload the owner's own videos to the owner's own account.

What it stores

The tokens are stored on the owner's own computer and are not shared with anyone. The tool does not collect, store or sell data about viewers, followers or any other TikTok users, and it uses no analytics or advertising trackers.

Removing access

The owner can disconnect the tool at any time in TikTok under Settings, Security and permissions, Manage app permissions. Disconnecting invalidates the stored tokens, which are then deleted.
